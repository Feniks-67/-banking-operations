# -customer-s-banking-operations
Работа над виджетом банковских операций клиента. 
# Проект: обработка и фильтрация банковских операций

## Цель проекта

Проект реализует базовый модуль `processing` для работы со списком операций (транзакций). Основные возможности:

- **Фильтрация операций по статусу** — выделение записей с нужным значением поля `state` (по умолчанию `EXECUTED`).
- **Сортировка операций по дате** — упорядочивание записей по полю `date` в формате ISO 8601 (по убыванию или возрастанию).

Модуль полезен для предварительной обработки данных перед отображением, экспортом или дальнейшей аналитикой.

# Банковские операции

Проект реализует функционал банковских операций с маскированием чувствительных данных и UI-виджетами.

## Установка и конфигурация

1. Клонируйте репозиторий:  
   `git clone https://github.com/Feniks-67/-banking-operations`
2. Перейдите в директорию проекта:  
   `cd banking-operations`
3. Убедитесь, что установлен Python версии 3.9 или выше.
4. Установите зависимости с помощью Poetry:  
   `poetry install`
5. При необходимости настройте переменные окружения (см. файл `.env.example`).

## Зависимости

- Python >= 3.9
- Poetry (для управления зависимостями)
- Основные пакеты (указаны в `pyproject.toml`):
  - `pytest` — для запуска тестов;
  - прочие библиотеки, требуемые для реализации функционала (автоматически устанавливаются через `poetry install`).


## Структура проекта

- `src/masks.py` — логика маскирования данных.
- `src/widget.py` — реализация виджета банковских операций.
